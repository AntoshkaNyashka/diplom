# Иерархия рекомендательной системы подбора туристических маршрутов

## Цель

Подобрать оптимальный туристический маршрут для пользователя на основе его предпочтений, ограничений и характеристик маршрутов.

## Уровень 1. Критерии выбора

| Критерий | Вес | Назначение в модели |
|---|---:|---|
| Соответствие интересам туриста | 0.20 | Проверяет совпадение интересов пользователя с признаками маршрута. |
| Бюджет поездки | 0.16 | Учитывает стоимость маршрута и превышение бюджета. |
| Желаемое направление | 0.14 | Учитывает выбранный город или регион. |
| Сезонность маршрута | 0.13 | Проверяет, подходит ли маршрут для выбранного сезона. |
| Длительность поездки | 0.11 | Сравнивает желаемое и фактическое количество дней. |
| Уровень активности | 0.08 | Учитывает физическую нагрузку маршрута. |
| Транспортная доступность | 0.06 | Проверяет совпадение или совместимость транспорта. |
| Климатические предпочтения | 0.04 | Сравнивает желаемый климат и климат направления. |
| Доступная среда | 0.04 | Учитывает доступность маршрута для маломобильных туристов. |
| Популярность и инфраструктура | 0.04 | Учитывает популярность города и туристическую развитость. |

Сумма весов равна 1.00.

## Уровень 2. Подкритерии

### Соответствие интересам туриста

- совпадение туристических интересов;
- тематические признаки города;
- тип маршрута.

### Бюджет поездки

- стоимость маршрута;
- запас относительно бюджета пользователя.

### Желаемое направление

- совпадение города;
- совпадение региона.

### Сезонность маршрута

- подходит ли сезон поездки;
- допустимость круглогодичного маршрута.

### Длительность поездки

- совпадение количества дней;
- допустимое отклонение длительности.

### Уровень активности

- низкая активность;
- средняя активность;
- высокая активность.

### Транспортная доступность

- полное совпадение транспорта;
- совместимый альтернативный транспорт.

### Климатические предпочтения

- совпадение желаемого климата;
- нейтральный климатический выбор.

### Доступная среда

- уровень доступности маршрута;
- обязательное требование доступной среды.

### Популярность и инфраструктура

- популярность города;
- развитость туристической инфраструктуры.

## Уровень 3. Альтернативы

Альтернативами являются конкретные туристические маршруты, сформированные из базы городов и шаблонов маршрутов:

```text
Маршрут = город + тип маршрута + сезон + длительность + цена + транспорт + уровень активности
```

В проекте используется CSV-база городов. Для каждого города создается несколько типов маршрутов: обзорный, гастрономический, активный, культурный, семейный и фототур.

## Итоговая оценка маршрута

Итоговый балл маршрута рассчитывается как взвешенная сумма оценок по критериям:

```text
score = сумма(оценка_критерия * вес_критерия) * 100
```

После расчета маршруты сортируются по убыванию итогового балла. Пользователю показываются лучшие варианты и текстовое объяснение причин рекомендации.

## Связь с кодом

Веса критериев находятся в словаре `CRITERIA_WEIGHTS` файла `tourism_recommender.py`. Подкритерии описаны в `CRITERIA_SUBLEVELS`. Расчет итоговой оценки выполняется функцией `score_route()`.
